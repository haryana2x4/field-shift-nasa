# Field Shift: Adapting Farms with NASA Data

Spatial Virtual Farm Simulation & Decision-Support System leveraging open NASA Earth observations (NASA POWER, MERRA-2, GEOS) to empower farmers and agronomists with climate-resilient crop rotation and groundwater conservation.

## Features
- **Real-Time NASA Observations**: Live queries for Temperature, Precipitation, Root/Surface Soil Wetness, Solar Insolation, Wind Speed, Humidity, Dew Point, VPD, and GDD.
- **Orien Agro-Advisor**: Gamified AI Agro-Advisor bot guiding optimal crop rotations.
- **Decision Support Portal**: Interactive charts, soil metrics, and crop recommendations.

## Quick Start

1. Install requirements:
   ```ash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```ash
   python app.py
   ```

3. Open `http://127.0.0.1:5000` in your web browser.
